# Руководство по сбору данных магазина Ozon

## Обзор

Система теперь может собирать данные напрямую с вашего магазина Ozon для создания более точных рекомендаций и реальных планов действий.

## Что собирается

### 1. Базовая информация о продавце
- Название магазина
- Рейтинг продавца
- Количество отзывов
- Количество товаров
- Дата регистрации на Ozon
- Описание магазина

### 2. Информация о товарах
- Общее количество товаров
- Топ товары
- Категории товаров

### 3. Информация об отзывах
- Общее количество отзывов
- Распределение рейтингов
- Последние отзывы

### 4. Информация о рейтинге
- Общий рейтинг
- Детализация рейтинга
- Тренд рейтинга

## Как использовать

### Способ 1: Через веб-интерфейс

1. Откройте http://localhost:5000
2. Перейдите на вкладку "Магазин Ozon"
3. Введите URL вашего магазина (или используйте предзаполненный)
4. Нажмите "Собрать данные магазина"
5. Дождитесь завершения сбора данных
6. Нажмите "Показать метрики магазина" для просмотра результатов

### Способ 2: Через API

```bash
POST /api/store/collect
{
    "seller_url": "https://www.ozon.ru/seller/cordus-sacrus-metodika-neyrofiziologa-koryukalova-2479303/"
}
```

## Использование данных в рекомендациях

Собранные данные автоматически используются для:

1. **Анализа рейтинга**
   - Сравнение с целевым рейтингом (4.7+ для медицинских товаров)
   - Рекомендации по улучшению рейтинга
   - Планы действий для повышения рейтинга

2. **Анализа отзывов**
   - Оценка количества отзывов
   - Рекомендации по сбору отзывов
   - Стратегии работы с отзывами

3. **Анализа контента магазина**
   - Проверка наличия описания
   - Рекомендации по улучшению контента
   - Планы по созданию контента

4. **Интеграции с общей аналитикой**
   - Данные магазина дополняют данные из отчетов
   - Создаются комплексные рекомендации
   - Формируются реальные планы действий

## Рекомендации на основе данных магазина

Система автоматически генерирует рекомендации:

### Рейтинг магазина
- **Критично низкий** (< 4.5): Срочные действия по улучшению
- **Ниже целевого** (< 4.7): Планы по достижению целевого рейтинга
- **Хороший** (4.7+): Рекомендации по поддержанию

### Отзывы
- **Недостаточно отзывов** (< 100): Стратегии сбора отзывов
- **Мало отзывов с фото**: Планы по увеличению фото-отзывов
- **Негативные отзывы**: Планы по работе с негативом

### Контент магазина
- **Отсутствует описание**: Планы по созданию описания
- **Неполная информация**: Рекомендации по дополнению

## API Endpoints

### POST /api/store/collect
Сбор данных с магазина Ozon

**Параметры:**
- `seller_url` (опционально): URL магазина
- `seller_id` (опционально): ID продавца

**Ответ:**
```json
{
    "success": true,
    "message": "Данные магазина успешно собраны",
    "data": {
        "seller_id": "2479303",
        "seller_info": {...},
        "products_info": {...},
        "reviews_info": {...},
        "rating_info": {...}
    }
}
```

### GET /api/store/metrics
Получение метрик магазина

**Ответ:**
```json
{
    "success": true,
    "data": {
        "metrics": {
            "seller_name": "...",
            "rating": {...},
            "reviews": {...},
            "products": {...}
        },
        "recommendations": [...]
    }
}
```

## Хранение данных

Собранные данные сохраняются в:
- `data/store_data.json` - полные данные магазина

Данные автоматически загружаются при следующем запуске системы.

## Ограничения

1. **Скорость сбора**: Ozon может ограничивать частоту запросов
2. **Динамический контент**: Некоторые данные могут быть в JavaScript, требуется дополнительная обработка
3. **Авторизация**: Для некоторых данных может потребоваться авторизация

## Примеры использования

### Пример 1: Сбор данных при первом запуске
```python
from collectors.ozon_store_collector import OzonStoreCollector

collector = OzonStoreCollector(
    seller_url="https://www.ozon.ru/seller/cordus-sacrus-metodika-neyrofiziologa-koryukalova-2479303/"
)
data = collector.collect_all()
collector.save_to_file()
```

### Пример 2: Использование в аналитике
```python
from analytics.store_analytics import StoreAnalytics

store_analytics = StoreAnalytics()
store_analytics.load_store_data(data)
metrics = store_analytics.get_store_metrics()
recommendations = store_analytics.get_store_recommendations()
```

## Поддержка

При возникновении проблем:
1. Проверьте правильность URL магазина
2. Убедитесь, что магазин доступен публично
3. Проверьте интернет-соединение
4. Попробуйте использовать seller_id вместо URL
