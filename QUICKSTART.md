# Быстрый старт

## Установка и запуск

### Windows
```bash
run.bat
```

### Linux/Mac
```bash
chmod +x run.sh
./run.sh
```

### Вручную
```bash
pip install -r requirements.txt
python app.py
```

## Использование

1. **Откройте браузер**: http://localhost:5000

2. **Загрузите файлы**:
   - Перетащите файлы в область загрузки
   - Или нажмите "Обработать папку upload" для автоматической обработки всех файлов

3. **Просмотрите аналитику**:
   - Перейдите на вкладку "Аналитика"
   - Увидите метрики продаж, финансов, логистики

4. **Получите рекомендации**:
   - Перейдите на вкладку "Рекомендации"
   - Система покажет рекомендации по улучшению показателей

## Поддерживаемые файлы

- `orders.csv` - отчет по заказам
- `returns_report*.xlsx` - отчет по возвратам
- `stocks_report*.xlsx` - отчет по остаткам
- `*начислениям*.xlsx` - отчет по начислениям
- `*юнит*экономика*.xlsx` - юнит-экономика

## Структура данных

Все обработанные данные сохраняются в папке `data/` для последующего использования.

## API

Система предоставляет REST API для интеграции:

- `POST /api/upload` - загрузка файла
- `POST /api/process-folder` - обработка папки
- `GET /api/analytics` - получение аналитики
- `GET /api/recommendations` - получение рекомендаций
- `GET /api/reports/list` - список отчетов
