# Система аналитики и рекомендаций для Ozon

Комплексная система для анализа отчетов Ozon с автоматической обработкой файлов, расчетом ключевых метрик и генерацией рекомендаций по улучшению показателей.

## Возможности

- 📊 **Автоматическая обработка отчетов** - поддержка CSV и Excel файлов
- 📈 **Комплексная аналитика** - расчет метрик продаж, финансов, логистики, клиентов
- 💡 **Умные рекомендации** - автоматические рекомендации на основе лучших практик Ozon
- 🎯 **Веб-интерфейс** - удобный UI для загрузки файлов и просмотра аналитики
- 🔄 **Автоматическая загрузка** - обработка всех файлов из папки upload
- 🏪 **Сбор данных магазина** - автоматический сбор информации с магазина Ozon
- ⚙️ **Анализ настроек кабинета** - проверка соответствия настроек рекомендациям и возможностям кабинета
- 📚 **Документация бренда** - учет товаров, комплектов и реализованных функций
- 📦 **Анализ карточек товаров** - детальный анализ каждой карточки с SEO, продажами и отзывами

### 🆕 Новые возможности (Ozon 2025)

- 🔍 **SEO-анализ** - оценка оптимизации карточек товаров для нового алгоритма ранжирования
- ⭐ **Анализ отзывов** - метрики отзывов, тональность, скорость ответов (критично для ранжирования)
- 📢 **Анализ рекламы** - эффективность рекламных кампаний, ROI, оптимизация ставок
- 📊 **Ranking Factors Score** - комплексная оценка факторов ранжирования Ozon 2025
- 🎯 **Рекомендации по новому алгоритму** - стратегии органического продвижения без рекламы
- 📈 **Метрики маркетплейса** - расширенные метрики: GMV, LTV, CAC, Retention

## Поддерживаемые типы отчетов

1. **Заказы** (orders.csv) - отчет по заказам с детальной информацией
2. **Возвраты** (returns_report.xlsx) - отчет по возвратам товаров
3. **Остатки** (stocks_report.xlsx) - отчет по остаткам на складах
4. **Начисления** (Отчет по начислениям.xlsx) - финансовые начисления
5. **Юнит-экономика** (Юнит-экономика.xlsx) - экономические показатели по товарам

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите приложение:
```bash
python app.py
```

3. Откройте в браузере: http://localhost:5000

## Использование

### Способ 1: Автоматическая обработка папки

1. Поместите файлы отчетов в папку `upload/`
2. Запустите приложение - файлы будут обработаны автоматически
3. Или нажмите кнопку "Обработать папку upload" в интерфейсе

### Способ 2: Загрузка через UI

1. Откройте веб-интерфейс
2. Перетащите файлы в область загрузки или выберите файлы
3. Файлы будут автоматически обработаны

### 🆕 Анализ карточек товаров

Система автоматически анализирует все карточки товаров из магазина:

1. **Автоматический анализ** - при загрузке данных система анализирует все карточки
2. **Сводка по каждой карточке** - детальный анализ SEO, продаж, отзывов
3. **Рекомендации** - персональные рекомендации для каждой карточки
4. **Экспорт в Excel** - экспорт полного анализа всех карточек

**Доступ через API:**
- `GET /api/products/cards` - получить анализ всех карточек
- `GET /api/products/card/<sku>` - получить сводку по конкретной карточке
- `GET /api/products/cards/export` - экспортировать анализ в Excel

**Что анализируется:**
- SEO-оптимизация (заголовок, описание, характеристики, медиа)
- Продажи (выручка, количество заказов, средняя цена)
- Отзывы (рейтинг, тональность, скорость ответов)
- Общий score карточки и статус
- Персональные рекомендации по улучшению

## Метрики аналитики

### Метрики продаж
- Общая выручка
- Количество заказов
- Средний чек
- Конверсия заказов
- Процент отмен
- Топ-10 товаров

### Финансовые метрики
- Маржинальность
- Общая сумма скидок
- Анализ по способам оплаты
- Выручка продавца vs оплата покупателя

### Логистические метрики
- Среднее время доставки
- Распределение по способам доставки
- Распределение по складам
- Топ регионы доставки

### Метрики клиентов
- Сегментация клиентов (Премиум/Обычные)
- Средний чек по сегментам
- Распределение по способам оплаты

### Метрики остатков
- Общие остатки на складах
- Зарезервированные товары
- Товары в пути
- Товары с нулевыми остатками

### Метрики возвратов
- Общее количество возвратов
- Процент возвратов
- Причины возвратов
- Статусы возвратов

### 🆕 Новые метрики (Ozon 2025)

#### SEO-метрики
- **SEO Score** - оценка оптимизации карточек (0-100)
- Анализ заголовков, описаний, характеристик
- Оценка медиа-контента (фото, видео)
- Рекомендации по улучшению SEO

#### Метрики отзывов
- Средний рейтинг товаров
- Процент ответов на отзывы
- Среднее время ответа на отзывы
- Процент отзывов с фотографиями
- Анализ тональности отзывов

#### Ranking Factors Score
- **Общая оценка факторов ранжирования** (0-100)
- Релевантность (SEO) - 25%
- Цена и конкурентоспособность - 20%
- Условия доставки - 20%
- Отзывы покупателей - 25% (критично!)
- Рейтинг и конверсия - 10%

#### Метрики рекламы
- ROI рекламных кампаний
- CPC/CPO метрики
- Конверсия из рекламы
- Эффективность кампаний

#### Расширенные метрики маркетплейса
- GMV (Gross Merchandise Value)
- LTV (Lifetime Value)
- CAC (Customer Acquisition Cost)
- Retention Rate
- Inventory Turnover

## Система рекомендаций

Система автоматически генерирует рекомендации по следующим категориям:

- **Продажи** - оптимизация конверсии, снижение отмен
- **Финансы** - улучшение маржинальности, оптимизация скидок
- **Логистика** - ускорение доставки, оптимизация складов
- **Остатки** - управление запасами, предотвращение дефицита
- **Возвраты** - снижение процента возвратов
- **Клиенты** - работа с сегментами клиентов
- **Товары** - оптимизация ассортимента

### 🆕 Новые категории рекомендаций (Ozon 2025)

- **SEO и контент** (критично) - оптимизация карточек для нового алгоритма
  - Оптимизация заголовков и описаний
  - Добавление Rich-контента
  - Видео в карточках
  - Мини-лендинги

- **Работа с отзывами** (критично) - управление отзывами для ранжирования
  - Автоматизация ответов на отзывы
  - Стимулирование отзывов с фото
  - Мониторинг тональности
  - Улучшение рейтинга

- **Рекламная стратегия** - оптимизация рекламных кампаний
  - Оптимизация ставок "Трафаретов" (минимум 7 руб)
  - Использование "Вывод в топ"
  - Анализ эффективности CPC/CPO
  - Акционные механики

- **Факторы ранжирования** - комплексное улучшение для органического продвижения
  - Стратегия без рекламы
  - Улучшение всех факторов ранжирования
  - Конкурентный анализ цен
  - Оптимизация доставки

Приоритеты рекомендаций:
- 🔴 **Critical/High** - требует немедленного внимания
- 🟡 **Medium** - важно для улучшения показателей
- 🟢 **Low** - рекомендации для оптимизации

## Лучшие практики Ozon

Система рекомендаций основана на актуальных стратегиях и лучших практиках работы на Ozon:

1. **Управление остатками** - поддержание оптимального уровня запасов (30 дней продаж)
2. **Ценообразование** - мониторинг конкурентов и оптимизация цен
3. **Качество карточек** - детальные описания, качественные фото, характеристики
4. **Логистика** - распределение по складам для ускорения доставки
5. **Работа с клиентами** - привлечение премиум-сегмента
6. **Снижение возвратов** - улучшение качества товаров и описаний

### 🆕 Актуальные стратегии Ozon 2025-2026

Система учитывает изменения алгоритма ранжирования (июнь 2025):

1. **Новый алгоритм ранжирования**
   - Объединение органических и рекламных факторов
   - Возможность попадания в топ без рекламы
   - Критическая важность отзывов и SEO

2. **Критические факторы ранжирования**
   - Релевантность описания (SEO) - 25%
   - Цена и конкурентоспособность - 20%
   - Условия доставки - 20%
   - Отзывы покупателей - 25% (критично!)
   - Рейтинг и конверсия - 10%

3. **Рекламные инструменты 2025**
   - "Трафареты" - минимум 7 руб/клик (было 3)
   - "Вывод в топ" - топ-12 поиска с VCG-аукционом
   - Объединение CPC и CPO ставок
   - Акционные механики
