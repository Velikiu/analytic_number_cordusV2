API (OZON)

Автозагрузка отчётов за последние месяцы

Автоматически скачивает выбранные типы отчётов помесячно за указанный период и добавляет их в аналитику.

Ручной запрос отчёта

Типы и коды отчётов — по документации OZON. Укажите report_type, период — и запросите создание. После готовности — скачивание в папку upload.
