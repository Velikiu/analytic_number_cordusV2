# Исправление сбора данных магазина

## Проблема

Ozon блокирует простые HTTP запросы и использует динамический контент (JavaScript), что делает простой парсинг HTML неэффективным.

## Решение

Система теперь использует многоуровневый подход:

### 1. Попытка сбора через веб-скрапинг
- Парсинг HTML страницы
- Извлечение JSON данных из страницы
- Поиск данных в script тегах

### 2. Fallback на документацию бренда
Если веб-скрапинг не работает, система использует:
- Данные из `brand/brand_documentation.json`
- Информацию о товарах и комплектах
- Базовую информацию о бренде

### 3. Дополнение данными из отчетов
Система автоматически дополняет данные:
- Количеством товаров из отчетов
- Информацией о продажах
- Метриками из аналитики

## Что собирается

### Успешно (из документации бренда):
- ✅ Название магазина
- ✅ Количество товаров (9)
- ✅ Список товаров
- ✅ Комплекты товаров
- ✅ Описание бренда

### Требует доступа к кабинету или API:
- ⚠️ Рейтинг продавца
- ⚠️ Количество отзывов
- ⚠️ Детальная информация об отзывах

## Альтернативные способы получения данных

### 1. Использование Ozon Seller API
Для получения полных данных рекомендуется использовать официальный API:
- Регистрация в Ozon Seller API
- Получение API ключей
- Интеграция с системой

### 2. Использование данных из отчетов
Система автоматически использует данные из загруженных отчетов:
- Количество товаров
- Информация о продажах
- Метрики магазина

### 3. Ручной ввод данных
Можно вручную обновить `data/store_data.json` с актуальными данными:
- Рейтинг
- Количество отзывов
- Другая информация

## Текущее состояние

Система работает с:
- ✅ Данными из документации бренда
- ✅ Данными из отчетов Ozon
- ✅ Автоматическим дополнением информации

Рекомендации генерируются на основе:
- Документации бренда
- Данных из отчетов
- Анализа метрик
- Инструментов Ozon Seller
