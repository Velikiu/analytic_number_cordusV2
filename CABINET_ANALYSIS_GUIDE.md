# Руководство по анализу настроек кабинета Ozon

## Обзор

Система теперь анализирует настройки кабинета продавца Ozon на основе:
- Документации о бренде (товары, комплекты, что уже сделано)
- Инструментов Ozon Seller (возможности кабинета)
- Реальных данных из отчетов
- Данных магазина

## Инструменты Ozon Seller

### 1. Управление товарами
- Создание и редактирование карточек
- Массовое редактирование
- Шаблоны товаров
- До 30 фотографий на товар
- Видео-обзоры

### 2. Ценообразование
- Автоматическое ценообразование
- Акции и скидки
- Промокоды
- Рассрочка (0-0-6, 0-0-12)

### 3. Продвижение
- Ozon Advertising (реклама в поиске, каталоге)
- Бустинг (виртуальный, эластичный, супербустинг)
- Промо-размещения

### 4. Логистика
- FBO (Fulfillment by Ozon)
- FBS (Fulfillment by Seller)
- Управление остатками
- Прогнозирование спроса

### 5. Аналитика
- Дашборд продавца
- Отчеты (продажи, остатки, возвраты, начисления)
- ABC/XYZ анализ

### 6. Работа с отзывами
- Модерация отзывов
- Ответы на отзывы
- Программа лояльности

### 7. Профиль продавца
- Настройки магазина
- Описание магазина
- Сертификаты и документы

### 8. Автоматизация
- API интеграция
- Автоматические уведомления

## Рекомендации по настройкам

Система генерирует рекомендации с конкретными планами действий:

### Пример: Создание комплектов
```
Категория: Настройки кабинета
Приоритет: High
Заголовок: Создание дополнительных комплектов

План действий:
⚡ Немедленно:
- Перейдите в "Товары" → "Создать товар" → "Комплект"
- Создайте комплект "Cordus Easy + Sacrus Easy"
- Настройте цену с выгодой 15-20%

📅 Краткосрочно:
- Создайте комплект "Cordus Plus + Sacrus Easy + Кейс"
- Создайте комплект "Массажер + Хондропротектор"

🎯 Долгосрочно:
- Разработайте стратегию комплектов
- Создайте сезонные комплекты

✅ Ожидаемый результат: Увеличение среднего чека на 30-40%
```

## API Endpoints

### GET /api/cabinet/analyze
Анализ настроек кабинета

**Ответ:**
```json
{
    "success": true,
    "data": [
        {
            "category": "Настройки кабинета",
            "priority": "high",
            "title": "...",
            "action_plan": {...}
        }
    ]
}
```

### GET /api/brand/info
Получение информации о бренде

**Ответ:**
```json
{
    "success": true,
    "data": {
        "brand_name": "Cordus & Sacrus",
        "products": {...},
        "product_sets": {...}
    }
}
```

## Использование

1. **Автоматический анализ**: Рекомендации по настройкам кабинета автоматически включаются в общие рекомендации

2. **Ручной анализ**: Используйте `/api/cabinet/analyze` для получения только рекомендаций по кабинету

3. **Информация о бренде**: Используйте `/api/brand/info` для получения информации о товарах и комплектах

## Обновление документации

Документация хранится в:
- `brand/brand_documentation.json` - информация о бренде
- `brand/ozon_seller_tools.json` - инструменты Ozon Seller

Для обновления:
1. Отредактируйте JSON файлы
2. Перезапустите систему
3. Рекомендации обновятся автоматически

## Интеграция с рекомендациями

Рекомендации по настройкам кабинета автоматически:
- Включаются в общий список рекомендаций
- Приоритизируются на основе данных
- Содержат конкретные планы действий
- Указывают точные пути в кабинете Ozon

Система учитывает:
- Что уже сделано (из документации бренда)
- Что можно сделать (из инструментов Ozon)
- Что нужно сделать (на основе данных)
