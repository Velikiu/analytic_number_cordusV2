# Руководство по системе рекомендаций

## Обзор

Система рекомендаций была полностью переработана на основе:
- Анализа реальных данных ваших продаж
- Лучших практик для медицинских товаров на Ozon
- Успешных кейсов продавцов в нише массажеров и товаров для спины
- Специфики медицинской ниши

## Структура рекомендаций

Каждая рекомендация теперь включает:

### 1. Базовая информация
- **Категория**: Продажи, Финансы, Логистика, Остатки, Возвраты, Клиенты, Медицинские товары, Контент, Ценообразование
- **Приоритет**: Critical (🔴), High (🟠), Medium (🟡), Low (🟢)
- **Заголовок**: Краткое описание проблемы
- **Описание**: Детальное объяснение ситуации с цифрами

### 2. План действий (Action Plan)

Каждый план разделен на этапы:

#### ⚡ Немедленно (1-3 дня)
Критичные действия, которые нужно выполнить в первую очередь

#### 📅 Краткосрочно (1-2 недели)
Действия для улучшения показателей в ближайшее время

#### 🎯 Долгосрочно (1-3 месяца)
Стратегические действия для устойчивого роста

#### ✅ Ожидаемый результат
Конкретные метрики, которые можно достичь

## Категории рекомендаций

### 1. Продажи
- Снижение процента отмен заказов
- Увеличение конверсии
- Повышение среднего чека через комплекты

### 2. Финансы
- Устранение отрицательной маржи
- Оптимизация маржинальности
- Пересмотр стратегии скидок

### 3. Логистика
- Оптимизация времени доставки
- Распределение по складам
- Работа с премиум-клиентами

### 4. Остатки
- Предотвращение дефицита
- Оптимизация остатков топ-товаров
- Автоматизация пополнения

### 5. Возвраты
- Снижение процента возвратов
- Работа с конкретными причинами возвратов
- Улучшение описаний и фотографий

### 6. Клиенты
- Привлечение премиум-клиентов
- Улучшение сервиса
- Программы лояльности

### 7. Медицинские товары (специфические)
- Оптимизация карточек для медицинской ниши
- Работа с сертификатами и документами
- Образовательный контент
- Работа с отзывами и рейтингом

### 8. Контент
- SEO-оптимизация для поиска Ozon
- Ключевые слова для медицинских товаров
- Оптимизация заголовков и описаний

### 9. Ценообразование
- Психология ценообразования
- Стратегия скидок
- Динамическое ценообразование

### 10. Успешные кейсы
- Применение стратегий успешных продавцов
- Премиум-позиционирование
- Комплексные решения

## Специфика медицинских товаров

Система учитывает особенности медицинской ниши:

### Критически важные элементы:
1. **Сертификаты и документы** - обязательны для доверия
2. **Медицинские показания** - помогают покупателям выбрать правильный товар
3. **Противопоказания** - снижают возвраты
4. **Инструкции по применению** - особенно важны для медицинских товаров
5. **Отзывы врачей** - повышают доверие
6. **Гарантия и сервис** - критичны для медицинских товаров

### Целевые метрики для медицинских товаров:
- **Маржа**: 20-30% (минимум 15%)
- **Конверсия**: 75-85%
- **Рейтинг**: 4.7-4.8
- **Возвраты**: 1-3%
- **Время доставки**: 2-3 дня

## Как использовать рекомендации

1. **Приоритизация**: Начните с рекомендаций Critical и High
2. **Планирование**: Используйте планы действий как чек-листы
3. **Отслеживание**: Регулярно проверяйте прогресс по метрикам
4. **Адаптация**: Адаптируйте планы под вашу специфику

## Обновление рекомендаций

Система автоматически обновляет рекомендации при:
- Загрузке новых отчетов
- Изменении метрик
- Обновлении данных

Рекомендации рассчитываются на основе актуальных данных из ваших отчетов Ozon.

## Поддержка

Все рекомендации основаны на:
- Анализе ваших реальных данных
- Лучших практиках Ozon
- Успешных кейсах в нише медицинских товаров
- Специфике маркетплейса

Система постоянно улучшается на основе новых данных и практик.
